# korektor rules

generated by `korektor rules --markdown`.

## core

| rule | default | what it catches |
| --- | --- | --- |
| `unclosed-if` | error | an %if without %endif |
| `stray-endif` | error | an %endif without %if |
| `stray-else` | error | an %else without %if |
| `stray-elif` | error | an %elif without %if |
| `branch-after-else` | error | an %elif or %else after %else |
| `unclosed-macro` | error | a %{, %( or %[ that's never closed |
| `trailing-backslash` | error | a line continuation at the end of the file |
| `not-a-tag` | error | a preamble line that isn't a tag, macro or section |
| `unknown-tag` | error | a preamble line looks like a tag but rpm doesn't know it |
| `duplicate-tag` | error | a single-valued tag is set twice for the same package |
| `missing-required-tag` | error | a package is missing Name, Version, Release, Summary or License |
| `missing-description` | error | a package has no %description |
| `section-for-unknown-package` | error | %files, %description or a scriptlet names a package no %package declares |
| `duplicate-source-number` | error | two Source or Patch tags share a number |
| `macro-in-comment` | warning | rpm expands macros in comments, so %define in a comment still defines |
| `needs-newer-rpm` | warning | uses syntax EL10's rpm 4.19 doesn't understand |
| `patchn-obsolete` | error | %patchN was removed in rpm 4.20, use %patch -P N |
| `changelog-date` | warning | a changelog entry has a bad date or the wrong weekday |
| `changelog-order` | warning | changelog entries should go newest first |
| `eval-error` | error | a macro or condition fails to evaluate the way rpm would fail |
| `line-outside-section` | error | text after %end that belongs to no section |
| `undefined-macro` | warning | a macro stays as literal text because nothing defines it (needs system macros loaded) |
| `bcond-unused` | warning | a bcond that no %{with} or %{without} ever checks |
| `duplicate-dependency` | warning | the same dependency is listed twice for one package |
| `unused-ignore` | warning | a rozbir: ignore directive that no longer suppresses anything |

## rpmlint

| rule | default | what it catches |
| --- | --- | --- |
| `deprecated-tag` | warning | BuildRoot, Group, PreReq and BuildPreReq do nothing or have better spellings |
| `clean-section` | warning | %clean isn't needed, rpm cleans the buildroot itself |
| `hardcoded-path` | info | a path spelled out where a directory macro exists |
| `mixed-tabs-spaces` | warning | the spec aligns with both tabs and spaces |
| `mixed-buildroot` | warning | both $RPM_BUILD_ROOT and %{buildroot} are used |
| `rpm-buildroot-usage` | error | the buildroot is touched in %prep or %build |
| `macro-in-changelog` | warning | rpm expands macros in %changelog, escape them as %% |
| `patch-not-applied` | warning | a Patch is declared but %prep never applies it |
| `setup-not-quiet` | info | %setup without -q lists every file it unpacks |
| `summary-ended-with-dot` | warning | Summary shouldn't end with a period |
| `summary-too-long` | warning | Summary is longer than 79 characters |
| `description-line-too-long` | warning | a %description line is longer than 79 characters |
| `make-check-outside-check-section` | warning | make check runs outside %check |
| `use-of-RPM_SOURCE_DIR` | warning | use %{SOURCEn} instead of $RPM_SOURCE_DIR or %{_sourcedir} |
| `unversioned-obsoletes` | warning | an Obsoletes without a version also obsoletes every future release of that package |
| `defattr` | info | %defattr(-,root,root,-) is the default and can go |
